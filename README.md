# DebtGuard AI — Debt Repayment & Reminder Assistant

Full-stack AI assistant that tracks your debts, alerts you before repayment due dates via an interactive calendar, browser/desktop notifications, and an automated daily background scheduler, and helps you optimize payoff with **Avalanche vs Snowball** strategies.

## Stack
- **Backend:** Node.js (Express) REST API + `node-cron` daily reminder scheduler
- **Database:** Built-in SQLite (`node:sqlite` at `backend/data/debts.db`) for zero-setup local use, plus PostgreSQL (`pg` + `backend/schema.sql`) via `DATABASE_URL` for production
- **Frontend:** React + Vite interactive dashboard, monthly due-date calendar, payoff planner, browser `Notification` alerts, and AI Copilot panel
- **AI Assistant:** Supports Google Gemini (`GEMINI_API_KEY`) or OpenAI (`OPENAI_API_KEY`), with a built-in natural-language debt parser and rule-based financial advisor fallback

## Database Tables
- `debts` — account details, balance, APR, minimum payment, next due date, recurrence (`MONTHLY`, `BIWEEKLY`, `WEEKLY`, `QUARTERLY`, `ONE_TIME`), status (`ACTIVE`, `PAID_OFF`, `ARCHIVED`)
- `payments` — recorded repayments that automatically deduct remaining balance and advance `next_due_date`
- `reminders` — deduplicated scheduled alerts generated by `node-cron` (`UNREAD` / `ACKNOWLEDGED`)
- `reminder_settings` — customizable lead days (`7,3,1,0`), daily cron expression, browser & optional SMTP email preferences, strategy, currency
- `chat_messages` — persistent AI conversation history

## Run Locally

### 1. Backend (API + Database + Daily Cron Scheduler)
```bash
cd backend
npm install
npm run seed      # Optional: adds 4 sample debts
npm test          # Runs automated API, scheduler, payoff, and AI tests
npm start         # Runs on http://127.0.0.1:4000
```

### 2. Frontend (Dashboard + Calendar + Browser Alerts)
```bash
cd frontend
npm install
npm run dev       # Runs on http://localhost:5174 (proxies /api -> 127.0.0.1:4000)
```

## Optional Production Environment Variables (`backend/.env`)
- `DATABASE_URL=postgresql://...` (uses `backend/schema.sql` automatically)
- `GEMINI_API_KEY=...` or `OPENAI_API_KEY=...` for LLM-powered AI chat
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD` for optional email alerts
